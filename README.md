# Fly:Over scenery packs

Regional scenery for [Fly:Over](https://github.com/adriantaylor/fly-over-releases), the Pegasus Quantum flexwing simulator: real terrain from LIDAR everywhere, finer still round the airfields, and trees and buildings that stream in as you fly.

**You don't download anything here yourself.** Install packs from inside the sim: **Menu → Scenery → Scenery packs**, then select a region. Each pack is a release of this repository (tagged with the pack's id), split into chunks the sim downloads, checks and unpacks for you.

| Pack | Covers |
|---|---|
| `sw-england` | South West England |
| `midlands` | East and West Midlands |
| `s-wales` | South Wales |
| `n-wales` | North Wales |
| `se-england`, `east-england`, `n-england`, `s-scotland`, `n-scotland` | later |

Terrain: Environment Agency LIDAR Composite (Open Government Licence), Welsh Government LIDAR (Open Government Licence). Buildings and airfields: © OpenStreetMap contributors (ODbL), Microsoft Global ML Building Footprints (ODbL).
